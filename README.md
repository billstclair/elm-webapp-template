elm-webapp-template

Stuff that is common to all webapps in Elm. Start from here.

    $ cp -R .../elm-webapp-template .../your-webapp
    $ cd .../your-webapp
    $ rm -rf elm-stuff/*

Update site/.sshdir to point to your web hosting directory.

Update site/index.html to replace "Elm Webapp Template" to your app's
name, and to change the GitHub link to point to your apps repository.
Also, update the "og:url" & "og:image" content to a URL to your webapp
hosting.

Update site/images/icon-192.png and site/images/icon-512.png to your
app's icon.

Update this README.md file to describe your webapp.

Edit src/Main.elm to be your webapp.
